🌸 Мировой мониторинг серверов Minecraft
Современный веб-портал и мониторинг игровых серверов Minecraft с интегрированным сообществом, форумом, каталогом версий и рейтингом PvP-бойцов. Проект разработан как единая интерактивная площадка для игроков со всего мира.

🚀 Основные возможности и функционал
Мониторинг игровых серверов:

Удобный каталог серверов с фильтрацией по популярным игровым режимам (Анархия, PvP / Дуэли, Выживание, BedWars) и регионам (СНГ, США / Америка, Европа, Азия).

Интерактивная строка быстрого поиска по названию, IP-адресу или версии клиента.

Подробная карточка каждого сервера: статус в реальном времени, текущий онлайн, рейтинг, ссылки на официальный Discord-сервер и магазин донатов, а также информация о периодичности вайпов.

Выделение топовых проектов с помощью VIP-закрепления в верхней части списка.

Интерактивный форум сообщества:

Отдельная вкладка для общения игроков, поиска кланов или обсуждения идей.

Возможность создавать новые темы с выбором категорий (Общие темы, Поиск кланов / игроков, Баги и предложения).

Система комментариев и ответов внутри тем.

Топ-20 PvP-игроков:

Боковая панель с рейтингом сильнейших бойцов сообщества.

Детальное отображение китов и тьеров (например, Crystal, Pot, SMP и уровни HT1, HT2) для каждого игрока.

Панель администратора (Админка):

Защищенная паролем панель управления прямо в интерфейсе сайта.

Добавление, редактирование и удаление серверов.

Управление топом PvP-игроков и модерация тем на форуме.

Инструменты для просмотра структуры баз данных и ручной синхронизации данных через API.

Дизайн и визуальное оформление:

Стильная темная тема в стиле GitHub / киберпанк.

Атмосферный анимированный фон с падающими лепестками сакуры.

Полная адаптивность под любые устройства (ПК, планшеты, смартфоны).
